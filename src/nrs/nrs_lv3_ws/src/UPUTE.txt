Za pokretanje simulacijskog okruženja:
    ros2 launch ur5_robotiq_sim ur5_robot_sim_moveit.launch.py
Za dodavanje ormarića na određenu poziciju:
    ros2 run ros_gz_sim create -file ./src/lv3/cabinet.urdf -name cabinet -allow_renaming true -x -0.2 -y 0.4 -z 0.948 -R 0 -P 0 -Y -1.57
Ako se mijenja pozicija, potrebno je promjeniti i "initial_pose" unutar "spawn_and_open_drawer.py"

Za pokretanje skripte koja otvara ormarić:
    ros2 run robot_control spawn_and_open_drawer

NAPOMENA! Nekad je potrebno dvaput pokrenuti skriptu za otvaranje ormarića
